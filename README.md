# 🎮 Simple Pygame Games

A collection of small games developed in Python to practice programming concepts and explore game development with **Pygame**.

## 📁 Projects

### 1. Hangman — Terminal Version

📂 [`hangman_game_in_terminal/`](./hangman_game_in_terminal/)

A classic Hangman game played directly in the terminal, featuring ASCII drawings, word guessing, and a penalty system.

### 2. Hangman — Pygame Version

📂 [`hangman_pygame/`](./hangman_pygame/)

A graphical version of Hangman built with Pygame, featuring an interactive interface, sound effects, a timer, and a replay option.

## 📖 Documentation

**Each project folder contains its own `README.md`**, with detailed information about the game, installation instructions, gameplay rules, and features.

Please refer to the corresponding README before running a game.

## 🛠️ Technologies

- Python 3
- Pygame
- Python standard libraries
